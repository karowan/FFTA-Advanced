## Preserve native resolution

`CCE60(unit, slot, first_out, last_out)` returns the full racial eight-byte-record bank, not its first record. Slot1 calls unit getterC92F0 selectors25/26; slot2 calls job getterC8570 onunit+8; slot3 uses Item job1/race0. The primary/secondary command byte1 also forces Item/race0 atCCEF8..CCF18. Out pointers are optional and receive bytes atCCF20/CCF28. Leave this ABI and original bounds unchanged.

For identifying the effective primary job, do not simply testunit+7. C92F0 atC9308..C930C passesunit+5 as the record andunit+7 as fallback. Job getter selectors25/26 atC895C/C896C follow job-record+5: zero means this record, FF means the fallback record (C8A02), another value redirects to that record (C8A0E). A narrow new helper should reproduce that alias resolution with bounded validation, then only activate custom iteration for the resolved Human2/Bangaa16 and a non-Item slot. Secondary resolution applies the same native record alias semantics withunit+8 as both arguments. Command2 by itself is insufficient: Bangaa Warrior also uses command2.

A full even-offset Thumb BL scan of the clean ROM found exactly the twelve CCE60 callsites below, all in native code. A full byte search found no literal080CCE61. This establishes the direct-call checklist and absence of that common indirect form; it is not proof against dynamically constructed pointers or external code.

## Bounded implementation strategy

Keep native bodies and original fallbacks. Add a pure membership helper operating on `(unit, slot, current_lesson)` or on an explicitly resolved job. It can scan at most17 entries to return the next real lesson and a separate success result. At each listed consumer, install a paired initialization and advance/termination shim: initialization chooses the first explicit lesson; advancement chooses the next exact entry, recomputes the record pointer from the unchanged bank plus8*lesson, and branches directly either to the original body or its original exit. Do not let a returned ordinal enter native AP reads, action records or row IDs.

A separate count/position API is also safe if its position belongs to that invocation's proven stack allocation. The stateless next-member form needs no additional persistent memory, no global iterator, and no fake first/last values. It survives26AB8 being called from within26D44. For the two fixed lists, an explicit successor lookup is bounded and trivial, including11→172 and43→105. Never let native `record += 8` run across either gap; changing only lesson increment would read the wrong action while displaying the correct lesson number.

For each shim, preserve all live native registers and re-establish only the branch flags the continuation consumes. Use the already tested dynamic C-stack alignment convention. Custom entry and backedge decisions must be paired; updating only the backedge leaves an empty or sentinel original interval uncontrolled. When no custom job is resolved, execute the displaced native instructions and original comparison without changing data or state.

For especially short predicates25FDC,26AB8,133D78 and1341EC, a new-only wrapper with native fallback can be smaller than multiple interior shims, but must reproduce the listed native filtering contracts. Avoid translating the large26D44 or133F70 bodies into generic C merely to change membership: they contain substantial original law/status/MP/special-action behavior worth preserving.
