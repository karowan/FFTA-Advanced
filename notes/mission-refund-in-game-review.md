## Inventory capacity

Native quest inventory02002B08 has64 four-byte records. Each contains local quest ID, flags, and a16-bit mission binding. Global quest IDs equal local+375; these paths must retain the quest namespace despite overlap with new equipment IDs.

Actual native full-inventory results open the SWAP screen. A required item bound to the completing mission cannot be discarded. The player can swap expendable unbound entries for incoming rewards and explicitly confirm the choice. There is no proven need for a capacity patch: the tested flow preserves both original first reward and the added reward. Declining/canceling must remain a deliberate native inventory decision; the patch does not silently discard another item.
