## Implemented consumers and corrected lifetime

The actual battle-body renderer is **0808F1F4**; its authenticated eight-byte
entry is `f0b557464e464546`, continuing at0808F1FD. It accepts the native actor
as r0 and its battle context as r1. The earlier080216F8 menu hook alone did not

Per-bank enabled-emission masks avoid scanning frames with no custom body.
Entry-array initialization is lazy on the first relevant emission. Later native
emissions still retire overwritten tags; the conservative presence mask does not
replace full attribute matching or clipping checks.

Native03000E10 suppresses palette DMA on ordinary repeated battle frames; it does
not mean the body disappears. The earlier restore-and-skip interpretation caused
two-out-of-three-frame palette dropout. A retained20-frame diagnostic onbefe2d94
records this directly in `battle/20260918T044455.295144Z/observed.json`: phase2
skips alternate with phase7 applications. The updated compositor reapplies custom
colors on those frames and latches their phase only when native palette DMA runs.
The earlier suspension test expected dropout and is superseded for that behavior.
No claim is made for unimplemented native color variants or late fade entry.

Exact8bpp tile-byte caching reduces repeated palette-demand scans. Each of32
entries stores64 bytes and their palette-bank mask. All64 bytes are compared
before reuse. Position/layout changes alone do not invalidate an identical tile;
different bytes always force a new scan. There is no hash-only shortcut.
First32 selected tiles are cached; additional tiles use the complete scanner.
Uncached planner output remains an independent comparison path in the tests.

Aligned block transfers copy the full native palette backup and visible generated
colors. The ARM helper preserves r4-r10/lr; callers supply nonzero word counts
divisible by8. Destinations are owned transient buffers, never native shadows.
Broad ARM-mode scan experiments were slower and were reverted. The final scan
uses the normal compiler configuration; the block-copy helper remains ARM code.

The reservation remains0203D000..0203F000,8KiB. State is now8060 bytes, leaving

at5596, compose phase at5604, visible colors at5608, cache at5928 and four profiling
halfwords at8052. The ROM stage uses153012 bytes. This is not a save-schema change.
