## Important adaptations

Do not install the whole engine master build. Its defaults include JP purchasing and one-bit abilities that remove AP. Those conflict with the approved design. Foundation uses selected independent features with local adaptations.

The original ROM has non-padding data after the tempting free-space-looking region at `0xA39920`. Allocate at `0x1000000`, beyond all original bytes, and expand to 32 MiB. The foundation currently ends at `0x10008E8`.

Morphing: do not hook the bare job-table getter `0x080C8570` with routines requiring a unit pointer in r3. Numerous native call sites do not supply that context. Our shim hooks `0x080C92F0`, the unit-aware getter. It calls the original first, tests unit `+0xEA & 4`, and applies only the visual handlers for selectors 4, 5, 0x22 and 0x23 when morphed. The monster table is `[2C,2E,31,33,36,38,3E,40,42]`. Separate size/generic/standing hooks from upstream are included and still require full-battle QA.

Sorting: upstream swaps 264-byte roster records and uses enemy RAM as scratch. Both star-clearing loops had `cmp r0,#48` with a 24-entry halfword table, reading one entry past the end. Generated bytecode changes both comparisons to 46. Marche and Montblanc swapping is disabled. The unrelated story/save patches following the main conditional include are omitted. External dispatch references remain unverified; byte-perfect roster swaps alone do not prove those safe.

Pub: the native option dispatch hook at `0x5D23C` maps indices `[1,0,2,3]`. Name pointers at `0x5567F0 + 0x29*4` and help IDs at `0x4C5170` are reordered together. The complete custom-others table infrastructure is unnecessary for this edit.

## Data records

Mission table `0x55AE4C`, 406 records, stride `0x46`. Internal IDs differ from displayed mission numbers.

| Internal record | Displayed mission | Edited field | Change |
|---|---|---|---|
| 69 | #066 A Dragon's Aid | +0x24 second reward | FFF7 random equipment → item 397 Wyrmstone |
| 183 | #168 Caravan Guard | +0x24 second reward | FFF3 random equipment → item 379 Elda's Cup; first reward 479 Caravan Musk retained |
| 111 | #103 Mythril Rush | +0x35 recruit | 01 → 92, copied from internal 66 / #063 Missing Prof. |

Mythril Rush's existing prerequisites include Present Day and Missing Prof. They are preserved, as are its repeat flag and native recruitment chance encoding. The extra-recruit rule still needs live tests for duplicates, failure/retry and death history.

**Shop gate translation:** displayed #005 Twisted Flow is internal record 7; #011 Pale Company is 13; #017 Desert Patrol is 19. The approved equipment ledger's `missionRecord` values `[null,5,11,17]` are nominal player-facing numbers, not usable engine record indices. Preserve the approved timing and translate it correctly when implementing stock.

Clan names use `0x565F14`; clan records start `0x564670`, stride 27. Name IDs 19 and 21 are Tricky Spirits and Wild Monsters. Composition matching gives full encounter formations 184/188 in the randomizer's indexing:

- Formation `0x54EE60`, five units at `0x53BB40`: Sprite, Sprite, Titania, Red Cap, Cream. Edit unit `0x53BBD0` to Goblin; copy native action/R/S fields from Goblin `0x53F530`.
- Formation `0x54EF00`, five units at `0x53BD80`: Jelly, Grenade, Icedrake, Malboro, Coeurl. Edit unit `0x53BDE0` to Thundrake; copy native action/R/S fields from Thundrake `0x5395C0`.

The clan-to-formation mapping is supported by compositions and table indexing, but still needs a real encounter test. Do not confuse Wild Monsters with Roda Dragons (formation 178).

ROM unit templates are 48 bytes: +1 job, +3 level, +5/+6 position, +7 facing, +0x14..0x27 ability bits, +0x28 reaction, +0x29 support. Dragon bits are race-wide: Thundrake's full native mask is `0F00` as a little-endian halfword, **not** `000F`. Goblin's action-only mask is `0001`.

Runtime roster: `0x02000080`, 24 entries of `0x108` bytes; +4 character ID, +5 job, +6 race, +7 special-job marker, +9 level.

Equipment: 375 records at `0x51D1A0`, stride 32; ID 1 is the first record. Equipment names use the record's first u16 as index into `0x526680`. Mission-item name indices are item ID + 123. Zeus' Mace=158, Materia Blade=26, Dark Gear=313, Genji Armor=298.

Do not repurpose missions merely named `dummy`: several late records drive unique-character events. Records 384–387 are tied to dismissed characters and cannot be used unchanged for our approved recovery routes. No safe new recovery slot has been selected yet.

## Testing and local tooling

`scripts/test-emulator-smoke.py` uses actual mGBA via libretro. For full EWRAM, use its memory-map descriptor at `0x02000000`: this core's memory-size API reports only 32768 for memory ID 2 despite the region having 262144 bytes. Test outputs stay under `build/test`; the harness never writes the user's original save.

`scripts/test-menu-routines.py` stubs five drawing/audio calls and explicitly handles standalone Thumb BL-tail opcode F800 with ARM7TDMI semantics; Unicorn's newer CPU decoder otherwise misreads some as Thumb-2 instructions. This limitation is documented, not treated as an in-game bug.

A separate quick-start QA fixture initially appeared stuck at world-map placement. Resolved September 14: the placement cursor moves freely by pixels, not one grid slot per short press. From the recorded seed, hold Right for 40 frames and Up for 16 before confirming Sprohm. This now drives `scripts/build-test-lab.py`, which saves through the real game menu and cold-loads that native save in the normal foundation ROM. Quick start remains absent from the foundation ROM, BPS and playable lab ROM. See `TESTING.md` and `build/test-lab/report.json`.

PowerShell directly runs ColorzCore. Node spawning that executable hit EPERM in this sandbox. Wheel extraction into `tools/arm-python` works; the unused pip-installed `tools/python` directories inherited inaccessible permissions and are not build dependencies.
