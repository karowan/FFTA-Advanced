## Map renderer investigation

Field caster icon40 already exists. It does not identify affected tiles, and
live outlines were unimplemented at this investigation checkpoint. The detached
compositor and capacity evidence below preceded the live owner described above. The following addresses were inspected
in the clean USA ROM; they are reverse-engineered observations, not accepted
hooks or a finished rendering design.

- Native range constructor `08022BA4` configures two colors and invokes
  `0801D2B8`. The latter changes background assignments, uses overlay state
  `02008168` and working tilemaps at `02003CB0`, and registers native processes.
  Reusing this constructor for persistent fields could conflict with Move/Act
  highlights. It must not simply run once per field or frame.
- `0801D624` draws a highlighted map cell using native height, projection and
  quarter-tile occlusion. `0801D130` stores two-bit color choices per quarter
  in the overlay state and chooses between its foreground/background planes.
  The known native colors are insufficient evidence of an unused persistent
  field layer or palette reservation.
- `0801CA78` converts tile/height coordinates into world coordinates;
  `0801C918` projects world coordinates; `0801C960` applies the current camera
  offset. `0801C984` combines projection and camera subtraction. C918 returns
  world depth, but1D624 explicitly replaces it with tileX+tileY before the
  quarter queries; its two lower quarters increment that value for an
  equal-height forward neighbor. Do not pass C918 world depth to these queries.
- `0801EC28` temporarily enables a native occlusion-query mode around
  `0801E710`. The latter inspects the native foreground map and returns a
  background priority, considering depth and height. A 32x16 sprite may cross
  more than one foreground region; using one priority for its whole diamond
  is not yet shown to match the native quarter-tile renderer.
- `08001F34` submits shapes to a bounded128-entry native OAM buffer through
  `080014C8`. The active buffer selector is `03000028`, counts `03000020`,
  buffers `03000030`. Other native sprite queues share the final128 hardware
  entries. `080012BC` assembles those queues. Merely staying inside the
  128-entry submission buffer would not establish that field markers preserve
  actors, HUD or other lower-priority queues.
- `080216F8` is native sprite submission from a sprite and rendering context;
  it eventually calls `08001F34`. `08097AD0` updates the existing status sprite
  rather than offering a dedicated persistent map-overlay layer.

A completed overlay needs independent capacity ownership, native camera and
height alignment, foreground occlusion, overlap deduplication, coexistence
with Move/Act targeting, and disappearance on actual field expiry. Caster
icons, changing frames, or a successful allocation do not establish these.
The deterministic field save/expiry scenarios above supply real lifetimes for
future visual assertions without requiring campaign play.
