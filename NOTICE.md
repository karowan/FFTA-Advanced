The artwork directory contains isolated custom class drawings and their native
palette conversions. Original game sprite references, mixed reference worksheets,
UI frames/lettering, screenshots, ROMs and third-party concept references are
excluded. Native palette colors and small alignment conventions are used for
compatibility with the game; no complete original game sprite is distributed.
