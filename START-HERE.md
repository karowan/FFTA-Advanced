# Start here

Read [the repository overview](README.md) for playing, development and current
limitations. The maintained player documentation is [MOD-README.md](MOD-README.md);
[MOD-RELEASE.md](MOD-RELEASE.md) explains the current package and launcher.

For an already provisioned local checkout, use **Play Mod.cmd**. Other launchers
preserve earlier builds and their separate saves. A fresh checkout does not
include a game, emulator, generated artwork or private test inputs.

The [original setup notes](notes/history/START-HERE.md) are historical.
